## Style files (`style/`)

Official Springer Nature LaTeX template package (used across Springer
journals, including CEAS Aeronautical Journal), downloaded from
<https://www.springernature.com/gp/authors/campaigns/latex-author-support>:

- `sn-jnl.cls` — the class file, pre-generated by Springer (no
  docstrip step needed, unlike the AIAA package).
- `sn-article.tex` (+ rendered `sn-article.pdf`) — starting template.
- `sn-bibliography.bib` — example bibliography.
- `bst/` — all bundled citation styles; per the submission guidelines
  ("numbers in square brackets", DOI links in the reference list),
  **`sn-vancouver-num.bst`** is the one matching CEAS Aeronautical
  Journal's citation format.
- `user-manual.pdf` — template usage manual.
- `fig.eps`, `empty.eps` — placeholder figures referenced by the template.

Also still here: `AEC_CEAS-AIDAA2025_paper_template.docx`, the Word
template for the Aerospace Europe Conference proceedings itself (2025
Turin edition, host: AIDAA) — kept in case the conference-proceedings
route (rather than the journal) is what's wanted; source:
<https://aidaa.it/wp-content/uploads/2025/03/MRP_auhtorInstructionsOA.docx>.

## Key submission requirements (from the journal's guidelines)

- Manuscript text: `.docx` or LaTeX; LaTeX (Springer Nature template)
  recommended for math-heavy content.
- Citations: numbered, square brackets, e.g. `[3]`, `[1-3, 7]`.
- References: DOIs as full links where available.
- Required "Declarations" section before the reference list: Funding,
  Competing interests, and (as applicable) Ethics approval, Consent,
  Data/Material/Code availability, Author contributions.
- Data availability statement required for original research articles.
- AI usage: must be documented in Methods (or equivalent) if used
  beyond copy-editing; LLMs do not qualify for authorship.
